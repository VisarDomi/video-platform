# video-auth
Get and update auth tokens used by video microservices.

## usage

`{
    "accounts": [
        {
            "email": "email-here@gmail.com",
            "password": "password-here",
            "provider": "tango"
        },
        {
            "email": "email-here-2@gmail.com",
            "password": "password-here-2",
            "provider": "tango"
        }
    ]
}`
